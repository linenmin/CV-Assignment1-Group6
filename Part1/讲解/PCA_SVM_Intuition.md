# PCA + SVM 直觉讲解

## 是的，50个特征向量完全来自80张训练图

---

## 第一步：把每张图变成一个"数字串"

想象把一张 100×100 的彩色脸部图像，像拆积木一样，把所有像素的 RGB 值**依次排成一行**：

```
[R₁, G₁, B₁, R₂, G₂, B₂, ..., R₁₀₀₀₀, G₁₀₀₀₀, B₁₀₀₀₀]
 ──────────────────────── 30,000个数字 ────────────────────────
```

80张图 → 80行 × 30,000列的矩阵。

---

## 第二步：PCA 在这 80 张图里找"共同变化规律"

PCA 的任务是：**在这 80 张脸里，最主要的"变化方向"是什么？**

举个生活类比：你有80张人脸，PCA会问：
- "哪个方向的差异最大？" → 可能是**明暗**（有些脸亮，有些脸暗）
- "第二大的差异方向？" → 可能是**左右朝向**
- "第三大的差异方向？" → 可能是**性别特征**
- ……以此类推，找 50 个这样的方向

每个"方向"重新排列成图片形状，就是一张 **Eigenface（特征脸）**，长这样：

```
Eigenface 1      Eigenface 2      Eigenface 3   ...
（捕捉明暗变化）  （捕捉朝向变化）  （捕捉其他差异）
  👤灰色鬼脸       👤侧面影子        👤模糊轮廓
```

> **关键点**：这 50 张 Eigenface 是从 80 张训练图中"提炼"出来的，完全不包含测试集的信息。

---

## 第三步：用 50 个 Eigenface 给每张人脸"打分"

有了这 50 张 Eigenface 后，对**任意一张新图**，我们问：

> "这张图和每个 Eigenface 有多像？"

每个 Eigenface 给出一个分数，最终得到 50 个数字：

```
新图  →  [0.82, -0.31, 0.15, 0.67, ..., -0.44]
          分数1   分数2   分数3  分数4  ...  分数50

          这就是这张图在 50 维空间里的"坐标"
```

这就是 **transform** 干的事：把一张 30,000 维的图压缩成 50 个坐标数字。

---

## 第四步：SVM 在 50 维空间里画"分界线"

现在把 80 张训练图都变成 50 维坐标，在这个 50 维空间里，每张图就是一个**点**，形状代表类别：

```
50维空间里（简化画成2D）：

        ●●    ← Jesse 的点（类别1）
      ●●  ●

    ■■■           ← Mila 的点（类别2）
     ■ ■■

         ◆◆◆      ← look-alike 的点（类别0）
          ◆◆
```

SVM 的任务就是**找一条最宽的"分界带"**，把三类点分开。

RBF 核的作用是：如果在 50 维空间里还分不开，就把这些点隐式地投影到更高维空间，直到能画出分界面为止。

---

## 第五步：预测新图

测试图来了：

1. 同样提取 50 维坐标（用训练集 fit 好的 Eigenface 打分）
2. 把这个点"放"进 50 维空间
3. 看它落在哪个区域 → 输出 0 / 1 / 2

```
测试图的50维坐标 → 落进 SVM 的哪个区域？
                         ↓
                    预测：Jesse (1)
```

---

## 一句话总结

| 步骤 | 做了什么 |
|------|---------|
| PCA fit | 从80张训练脸中找出50个"主要变化方向"（Eigenface） |
| PCA transform | 把任意一张脸投影到这50个方向上，得到50个坐标 |
| SVM fit | 在50维空间里学习三类点的分界面 |
| SVM predict | 看新图的50维坐标落在哪个区域 |
